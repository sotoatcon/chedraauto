# AGENTS.md

Reglas generales para trabajar en este repositorio:

1. No afectar funcionalidad no solicitada.
2. No modificar encoding ni acentos en el código.
3. No planchar código con versiones del repositorio sin autorización explícita.
4. No asumir funcionalidad: si hay ambigüedad o dudas en una definición, solicitar aclaración puntualmente antes de implementar.
5. No utilizar emojis.
6. Mantener comentada la funcionalidad del código (no borrar secciones comentadas existentes sin pedir permiso).
7. Si se hace referencia a un elemento web nuevo, o uno viejo deba actualizarse, dar mantenimiento respetando la estructura POM actual.
